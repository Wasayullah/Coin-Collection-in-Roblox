# Coin-Collection-in-Roblox
This is a simple coin collection game develoed in Roblox with luau scripts 

# How to Run 
You can run this game locally on your system 
Steps: 
     |__
         1. Download Roblox in to your system form here >> https://www.roblox.com/download
         2. Clone this repo using the command : "git clone https://github.com/Wasayullah/Coin-Collection-in-Roblox" 
            or just download the zip format of this code and later unzip.
         3. Launch Roblox and click the File option in the top left.
         4. Select open from a file.
         5. Go to the code file and select Mohammad.rbxl
         6. The Game will open in to the Roblox. 
         7. Now just Click F5 to Run the game or click the Run button.

         If you want to alter the scripts you can. Because all the scripts and elements are available in this repo
