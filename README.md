# 🪙 Coin Collection in Roblox

A simple and interactive **Coin Collection game** developed in **Roblox Studio** using **Luau** scripting. The project demonstrates basic Roblox game development concepts, including coin collection, player rewards, coin respawning, and player movement.

## 🎮 Features

* 🪙 Collect coins by interacting with them.
* 💰 Earn coins and track them using the player's leaderboard.
* 🔄 Coins automatically respawn after a set amount of time.
* 🔄 Rotating coins for an interactive visual effect.
* 🏃 Increased player movement speed.
* 📜 Clean and easy-to-understand Luau scripts.
* 🛠️ Fully editable Roblox Studio project.

## 🛠️ Technologies Used

* **Roblox Studio**
* **Luau**
* **Roblox Game Development**
* **Git & GitHub**

## 🚀 How to Run the Project

Follow these steps to run the game locally:

### 1. Install Roblox Studio

Download and install **Roblox Studio** from the official Roblox website:

[Download Roblox Studio](https://www.roblox.com/download)

### 2. Clone the Repository

Open your terminal or Git Bash and run:

```bash
git clone https://github.com/Wasayullah/Coin-Collection-in-Roblox.git
```

Alternatively, you can download the repository as a ZIP file and extract it on your computer.

### 3. Open the Project

1. Launch **Roblox Studio**.
2. Click **File** in the top-left corner.
3. Select **Open from File**.
4. Navigate to the cloned or extracted project folder.
5. Select the Roblox project file (`.rbxl`).
6. The game will open in Roblox Studio.

### 4. Run the Game

Once the project is open:

* Click the **Play** button in Roblox Studio, or
* Press **F5** on your keyboard.

You can now play and test the Coin Collection game.
